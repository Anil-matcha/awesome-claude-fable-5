# TypeScript example

Install Node.js 20 or newer, then install the official SDK:

```bash
npm install @typesafe-ai/sdk
export TYPESAFE_API_KEY="your-key"
npx tsx examples/typescript/quickstart.ts
```

The SDK infers answer types from the questions you define. See the [official
JavaScript SDK](https://github.com/typesafe-ai/typesafe-sdk-js) for client
options and the [TypeSafe JavaScript docs](https://docs.typesafe.ai/sdk/javascript)
for the current API.
